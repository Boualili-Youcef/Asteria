Expérimenter une dépendance indisponible.

Dans un terminal, depuis demo/playground :

docker compose stop redis
# Observer /ready 503 et /health 200 ci-dessus.
docker compose start redis

Le navigateur n’a aucun accès au daemon Docker. Aucun bouton de chaos ou de reset n’est exposé. La reprise peut prendre quelques secondes ; créer ensuite une nouvelle commande.

Sans outbox : un commit PostgreSQL peut précéder une erreur Redis. BLPOP ne fournit pas d’ACK durable. Ce laboratoire montre ces limites ; il ne les corrige pas.
